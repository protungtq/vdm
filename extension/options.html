VN Download Manager — options

The desktop app only accepts downloads from a paired extension. Paste the pairing code below once and the extension will send it with every download.

  1. Open VDM on your computer → Settings → Browser integration.
  2. Copy the pairing code shown there.
  3. Paste it here and click Save.

The code only ever travels to the VDM app on your own computer (127.0.0.1). If it stops working, make a new code in the app's Settings and paste it here again.
