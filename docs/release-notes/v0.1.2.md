### What's new in 0.1.2

- **Fixed:** reopening the browser could open many "Download File Info" windows at once, for old downloads from the browser's history (some with expired links). The browser extension now only hands over downloads that have just started, and each one only once.
- When several downloads arrive at the same moment, KDM now opens **one window with a checklist** instead of a window for each file.

After updating, close and reopen your browser once (or click the reload button of the KDM extension on `chrome://extensions`) so it uses the updated extension.
