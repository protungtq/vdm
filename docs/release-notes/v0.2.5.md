### VN Download Manager 0.2.5 — new in-app logo, full-colour tray icon

VN Download Manager (VDM) 0.2.5 finishes the new app icon rollout from 0.2.3: the logo shown inside the app now uses the new artwork, and the tray icon on Windows and Linux is the full-colour red icon instead of the faint single-colour glyph.

### What's new in 0.2.5

- **The logo inside the app uses the new artwork.** The title bars, dialogs and Settings now show the new red icon with the yellow swoosh and the Vietnamese flag badge, matching the app icon.
- **The tray icon is full colour on Windows and Linux.** The system tray now shows the red icon with the white download arrow, clearly visible on light and dark taskbars alike. On a Mac the menu-bar icon stays single-colour, as macOS tints it itself.
- No behaviour changes; everything else works exactly as in 0.2.4.
