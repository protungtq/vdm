### VN Download Manager 0.2.6 — Vietnamese interface

VN Download Manager (VDM) 0.2.6 brings the whole interface to Vietnamese: every menu, button, setting and message, plus the What's New window. The app follows your system language by default; you can also pick a language by hand in Settings → General → Language.

### What's new in 0.2.6

- **Vietnamese interface.** The whole app — menus, buttons, Settings, notifications and error messages — is now available in Vietnamese. New installs follow the system language automatically; pick another language any time in Settings → General → Language.
- **Linux builds.** VDM now ships AppImage and .deb packages for 64-bit Linux. On Linux the Update Available button opens the release page to download the new version.
- **The bundled browser extension now uses the current VDM brand icon** (red, white arrow, yellow swoosh, Vietnamese flag badge) in all sizes.
- No behaviour changes; everything else works exactly as in 0.2.5.
