### VN Download Manager 0.2.1 — new app icon

VN Download Manager (VDM) 0.2.1 replaces the app icon on Windows, Mac and Linux with the new VDM artwork: a download arrow over a globe, with the Vietnamese flag. The Android app and the VN Browser got matching new icons at the same time.

### What's new in 0.2.1

- **New app icon.** The new artwork replaces the old red download-arrow icon everywhere: the Windows installer and shortcuts, the Mac app and DMG, the Linux icon, and the logo shown inside the app.
