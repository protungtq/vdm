### VN Download Manager 0.2.2 — synced with Keyvan Download Manager 0.2.2

VN Download Manager (VDM) 0.2.2 syncs the upstream Keyvan Download Manager 0.2.1 and 0.2.2 changes: the browser button now downloads the video you clicked on pages with several videos, a "Download complete" window opens when a download finishes, and the update check works again on shared networks and VPNs.

### What's new in 0.2.2

- **Fixed: the browser's "Download video" button downloaded the wrong video.** On a page with several videos (a feed, a gallery, a list of previews) the button could send another video from the page. It now works out which video you clicked (its own file, the link to its page, or the stream it started loading) and downloads that one. **Reload the VDM extension** in `chrome://extensions` to get this fix.
- **A "Download complete" window.** When a download finishes, the progress window closes and a separate window opens on top of all other windows, with the file name, where it was saved, its size and speed, and **Open** / **Open folder** buttons. It can be turned off in the window itself or in Settings. Files the queue downloads in the background only show a notification.
- **Fixed: update check failed with "GitHub responded 403".** GitHub limits how often one internet address may ask for updates, so shared networks and VPNs could be refused. VDM now falls back to GitHub's release pages.
- **Fixed: the "Update Available!" button did nothing.** The app wrongly refused the download address when GitHub spelled the repository name with different letter case. The button now downloads and installs the update again, and shows the reason if something goes wrong instead of staying silent.
- **Update found too early.** If VDM looked for updates while a new release was still being built, the button sent you to the web page. VDM now waits until the installer is attached and checks again by itself.

**Because the update fixes are inside the app, install 0.2.2 by hand once** (the buttons on the project page); after that, automatic updates work again.
