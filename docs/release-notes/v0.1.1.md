### What's new in 0.1.1

- **YouTube downloads fixed.** "Requested format is not available" no longer appears: KDM now gives the video downloader what YouTube requires, keeps it up to date in the background, and retries once with an update if a site offers no video.
- **Several download queues.** Create as many queues as you like (for example *Night downloads*). Each queue has its own start/stop time, days, downloads at a time and action when it finishes. Right-click a download → **Move to queue**.
- **Queues download one file at a time** by default.
- **Select several downloads:** `Shift`+click for a range, `Ctrl`+click (`⌘` on Mac) to add one, or the new **Select all** button / `Ctrl+A`. Resume, pause or delete them together; deleting asks once and can also delete the files from disk.
- **macOS version** (Apple Silicon and Intel).
