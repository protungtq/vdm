### VN Download Manager 0.2.3 — new app icon

VN Download Manager (VDM) 0.2.3 refreshes the app icon everywhere: the installer, the installed app, the desktop shortcut and the download windows all use the new red download-arrow icon with the Vietnamese flag badge.

### What's new in 0.2.3

- **New app icon.** The new icon replaces the previous one on Windows, Mac and Linux. No behaviour changes in this release; everything else works exactly as in 0.2.2. If Windows keeps showing the old icon on an existing shortcut, log out and back in (or restart Explorer) to refresh the icon cache.
