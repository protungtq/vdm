### What's new in 0.1.3 — security update

- **Browser cookies are encrypted.** Cookies kept for unfinished downloads (needed for sites you're signed in to) are now encrypted by your operating system (Windows DPAPI / macOS Keychain) instead of being saved as plain text, and are deleted as soon as a download finishes.
- **Only KDM's own extension can talk to the app.** Web pages and other browser extensions can no longer send downloads to KDM.
- **Video tools are verified.** yt-dlp and ffmpeg are checked against their published SHA-256 checksums before they are used; a file that doesn't match is deleted and never run.
- Build tooling updated (no known vulnerabilities in `npm audit`).

### ⚠️ One step for the browser extension

The extension now has a fixed ID, so the copy you installed earlier stops working after this update. Reinstall it once:

1. Open `chrome://extensions` (or `edge://extensions`) and **Remove** the old KDM extension.
2. Click **Load unpacked** and select the extension folder again (**KDM → Settings → Browser integration → Open extension folder**).
